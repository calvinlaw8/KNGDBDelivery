# MongoDB 8.2.12 副本集验收说明

## 部署内容

- 副本集名称为 `rs0`，3 个成员地址由现场配置提供。
- 使用 keyFile 完成成员间认证，管理员账号只从受控配置获取。
- keyFile 必须为 `0400`，属主为 `mongodb:mongodb`。

## 验收步骤

```bash
ansible-playbook -i inventory/hosts mongodb/01_install.yml mongodb/02_configure.yml mongodb/03_auth.yml mongodb/04_verify.yml
ansible mongodb -m shell -a "systemctl is-active mongod"
```

使用现场凭据在受控终端验证 `rs.status().ok = 1`，确认 1 个 Primary 和 2 个 Secondary。模拟单节点故障并记录重新选举结果。

## 风险边界

副本集写入和选举需要多数节点。多数节点所在 AZ 故障时，剩余单节点不能继续提供正常写入服务。
