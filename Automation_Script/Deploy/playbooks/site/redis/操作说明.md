# Redis 8.2.8 主从 + Sentinel 验收说明

## 部署内容

- 1 个 Primary、2 个 Replica，节点地址由现场配置提供。
- 3 个 Sentinel，端口 26379，quorum 为 2。
- 客户端认证密码只从受控配置获取，不写入本文档或命令历史。

## 验收步骤

```bash
ansible-playbook -i inventory/hosts redis/01_install.yml redis/02_configure.yml redis/03_sentinel.yml redis/04_verify.yml
ansible redis -m shell -a "redis-cli info replication"
ansible redis -m shell -a "systemctl is-active redis-server redis-sentinel"
```

确认 Primary、Replica、Sentinel 均正常，且 Replica 已连接到 Primary。模拟单节点故障时，应记录 Sentinel 是否完成提升及业务中断时长。

## 风险边界

多数 Sentinel 不存活时不能假设会自动 Failover。2 AZ 场景中，多数节点所在 AZ 故障可能导致无法完成仲裁。
