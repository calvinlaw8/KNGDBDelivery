# 交付五离线数据库部署向导

## 向导会做什么

向导会收集管理节点、数据库服务器和四类组件集群的配置，生成本次部署使用的运行时文件，然后调用离线 Ansible 流程完成：

- Redis 3 节点主从与 Sentinel
- RabbitMQ 3 节点集群
- MongoDB 3 节点副本集
- MySQL GTID 主从与 Keepalived VIP

部署过程会修改目标服务器主机名、`/etc/hosts`、软件和服务配置。请确认目标服务器可以接受这些变更。

## 现场前置条件

- 目标服务器为 Ubuntu 24.04.x amd64/x86_64。
- 管理节点和目标服务器之间可以通过 SSH 连接。
- 已准备可用的 Linux 登录账号、密码以及 sudo 权限。
- 交付包中的离线安装包和 Ansible 依赖完整；部署过程不会联网下载软件。
- 每个组件组输入独立的网段前三段，例如 `10.20.14`，随后为每个节点输入最后一段主机号 `21`、`22`、`23`。

## 输入与安全

- Linux 登录凭据用于 SSH 和远程初始化；Redis、RabbitMQ、MongoDB、MySQL 凭据只用于对应服务。
- 密码和 RabbitMQ Cookie 会隐藏输入，并要求二次确认。
- 总览只显示敏感项“已输入”，不会显示密码或 Cookie。
- 输入过程中可返回总览修改；确认前选择取消不会执行部署。

## 预计耗时

首次部署通常需要约 10 至 30 分钟，实际时间取决于 SSH 连通性、磁盘性能和目标服务器数量。现场应预留故障排查时间。

完整项目说明请参阅仓库根目录的 `README.md`。部署完成后请结合 `验收记录/` 中的模板进行验收。
