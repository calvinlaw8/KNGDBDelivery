# eCopilot 数据库高可用部署向导

## 向导会做什么

向导会收集管理节点、数据库服务器和四类组件集群的配置，生成本次部署使用的运行时文件，然后调用离线 Ansible 流程完成：

## 启动前安全提示

本向导首次连接目标主机时不人工验证 SSH 主机指纹。该方式仅适用于受控部署网络，不建议在不可信网络中执行。执行前请确认目标 IP 属于本次授权部署范围，且网络路径没有被非授权设备接入。

- Redis 3 节点主从与 Sentinel
- RabbitMQ 3 节点集群
- MongoDB 3 节点副本集
- MySQL GTID 主从与 Keepalived VIP

## 固定部署版本

- Redis 8.2.8：3 节点主从与 Sentinel。
- RabbitMQ 4.2.9 + Erlang 27.3.4.16-1：3 节点集群。
- MongoDB 8.2.12：`rs0` 三节点副本集。
- MySQL 8.4.11 + Keepalived 2.2.8：GTID 异步主从与 VIP。

部署过程会修改目标服务器主机名、`/etc/hosts`、软件和服务配置。请确认目标服务器可以接受这些变更。

## 现场前置条件

- 目标服务器为 Ubuntu 24.04.x amd64/x86_64。
- 管理节点和目标服务器之间可以通过 SSH 连接。
- 已准备可用的 Linux 登录账号、密码以及 sudo 权限。
- 每个组件组录入时先输入该组主机 IP 地址的前三段，例如 Redis 输入 `10.20.14`；这一步只输入前三段，后续节点输入 `10` 时地址就是 `10.20.14.10`，如果后续直接输入完整 IPv4 地址 `192.168.10.10`，则直接使用 `192.168.10.10`，不再拼接前三段。
- 整组录入时会先连续录入 3 个节点 IP，再输入主机名前缀。例如普通前缀 `redis-node`，节点输入 `1`、`2`、`3` 会生成 `redis-node1`、`redis-node2`、`redis-node3`；以数字结尾的前缀 `T-Redis-0`，节点输入 `1`、`2`、`3` 会生成 `T-Redis-01`、`T-Redis-02`、`T-Redis-03`。主机名输入项中输入 `1`、`2`、`3` 会采用对应默认名称，输入完整主机名则使用输入值；留空前缀则逐台输入主机名。
- 输入主机名前缀后，普通前缀例如 `db-node`，节点输入 `1`、`2`、`3` 会生成 `db-node1`、`db-node2`、`db-node3`；如果输入数字结尾前缀 `T-Redis-0`，节点输入 `1`、`2`、`3` 会生成 `T-Redis-01`、`T-Redis-02`、`T-Redis-03`。节点项也可以直接输入完整主机名；留空前缀时则逐台输入完整主机名。必须保证所有节点主机名唯一。

## 输入与安全

- Linux 登录凭据用于 SSH 和远程初始化；Redis、RabbitMQ、MongoDB、MySQL 凭据只用于对应服务。
- 密码和 RabbitMQ Cookie 会隐藏输入，并要求二次确认。
- 总览只显示敏感项“已输入”，不会显示密码或 Cookie。
- 输入过程中可返回总览修改；确认前选择取消不会执行部署。
- 启动菜单选择“查看部署说明”可直接阅读本文件，阅读结束后返回启动菜单，不会创建运行时目录或开始配置录入。

## 凭据留存与授权查看

- 部署结束后，向导会把本次输入的完整账号、密码、RabbitMQ Cookie、节点 IP/主机名和 MySQL VIP 写入 `Automation_Script/Deploy/.runtime/credentials.txt`。
- `.runtime/` 目录权限为 `700`，`credentials.txt`、`config.env` 和安装摘要权限为 `600`；文件由 `umask 077` 配合临时文件原子替换生成。
- 终端只显示凭据文件路径，不显示明文。仅授权人员可在受控终端执行：`less Automation_Script/Deploy/.runtime/credentials.txt`。
- 禁止把凭据文件内容复制到普通操作日志、验收报告、终端回显或 Git。该目录已被 Git 忽略，但仍应限制本机访问权限。
- 凭据移交客户密码管理器并确认可用后，应删除本地 `.runtime/`，并轮换已交付的密码、Cookie 和通信认证信息。

## 预计耗时

首次部署通常需要约 10 至 30 分钟，实际时间取决于 SSH 连通性、磁盘性能和目标服务器数量。现场应预留故障排查时间。

完整部署说明请参阅随包根目录的 `README.md`。部署完成后请使用 `验收记录/` 中的验收模板进行记录。
